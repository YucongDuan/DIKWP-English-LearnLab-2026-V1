# DIKWP English LearnLab 2026 V1

Created by Yucong Duan (段玉聪).

A standalone, offline-first prototype for Chinese students learning English through a DIKWP evidence loop.

## Workflow

Learner profile → CSE/CEFR-aware diagnosis → Purpose Contract → DIKWP language loop → vocabulary/grammar/listening/speaking/reading/writing training → task missions → Learning Evidence Ledger → Error Ledger → AI Use Log → teacher/peer review → English Learning Passport.

## Quick start

Open `index.html` in a modern browser. No server, database, API key, model endpoint, account, or network is required.

Optional CLI:

```bash
python tools/run_english_plan.py examples/sample_learner.json --out outputs
```

## Boundaries

This system does not provide official language certification, exam prediction, automated high-stakes grading, placement decisions, discipline decisions, or ghostwriting. AI outputs must be logged and human-verified.
